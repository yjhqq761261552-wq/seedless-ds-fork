RP Duo Nova phosphor appearance

Visual reference

The user's RPNova-GBA-Shaders-2026-10-24 preset and reference screenshot.
The original preset uses Phosphor Dot v3.3 by Roc-Y (脑浆油条), followed by
the public-domain NDS color profile and image-adjustment shaders.

The RP Duo circle coverage is implemented in this fork using four-node
Gauss-Legendre integration of disk/pixel intersections. It follows the
project license. The disk lattice uses the current draw's output dimensions
and native DS dimensions, with the saved 0.4 dot scale and 0.4 opacity.

The backup's NDS profile uses gamma 2.0, sRGB with white balance enabled,
and luminance 0.915. The final HSV saturation and luminance are both 1.3.
The fixed temperature, black-level and gamma settings come from the saved
preset and the shader defaults recorded with the user's original backup.
