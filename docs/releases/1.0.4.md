# SeedlessDS 1.0.4-stickfix：摇杆串键修复

针对 RP Nova 左摇杆左右难触发、经常触发上下的反馈修复代码。versionCode 114，包名 com.seedlessds.app.debug，arm64-v8a，最低 Android API 21。使用与之前测试版相同的 Debug 签名，可覆盖安装，保留设置和存档。

## 修复内容

- 将 X/Y 独立阈值判断改为八方向角度分区。比如 X=0.8、Y=0.08 原来会同时发送右和下，现在只发送右；四个真正的斜向仍可使用。
- 读取设备 X/Y 的 MotionRange.flat，与用户死区取较大值过滤中心漂移。
- 过滤 HAT 轴噪声；明确推杆优先于 HAT，不再因 HAT 任意非零值覆盖摇杆。有效 HAT 按下时也不会被轻微摇杆漂移抢占。
- 启用现有“不允许十字键斜向”设置时，左摇杆只发送幅度最大的方向。
- 菜单导航每次选择一个方向，避免同一输入连续触发横向和纵向；手柄断开时释放输入。
- 保留回溯、双屏和之前的输入延迟修复，未重置用户的死区与按键绑定。

## 验证

- assembleDebug、testDebugUnitTest、lintDebug 全部成功。

- Lint 0 项错误、18 项警告。
- APK 签名验证通过；5 个原生库的 ZIP/ELF 均满足 16 KiB 对齐检查。
- 192 个着色器资源与源码、上一版一致；413 个原生源码及关联文件逐一比较无改动，本次没有重复运行无关的原生回溯测试。
- 源码包 725 个文件逐一核对一致，不含构建目录、SDK、缓存及 local.properties；包含 JVM 测试和 STICK_FIXES.md。

没有 RP Nova 真机或该设备原始轴事件数据，本次验证的是代码逻辑与构建，未进行真机操作测试。请覆盖安装后重点测试左摇杆慢推/满推左右、上下、四个斜向及回中，再比较实体十字键。无需卸载，也无需重新设置绑定。如果仍有静止漂移，可在“按键 → 摇杆死区”适当提高数值对比。
