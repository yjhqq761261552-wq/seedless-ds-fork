# SeedlessDS 1.0.5-rewindperf

本次修复回溯开启时的周期性卡顿。用户在 RP Nova 上运行《宝可梦 心金》，回溯开启时 1 倍/2 倍 3D 都掉速，关闭后恢复约 99–100%。检查确认上一版每秒在模拟线程计算 CRC 和压缩整份快照，即使挂机也会触发，这是之前回溯实现中的性能问题。

## 修复

- 模拟线程只复制游戏状态；CRC 和 zlib 压缩移到低优先级后台线程，后台只访问独立副本。
- 复用原始快照缓冲，减少每秒大缓冲分配/释放。
- 一个后台线程、一个在途任务、一个完成结果。后台忙时跳过记录机会，不阻塞模拟，不积压任务。
- 后台任务标记时间线，读档/重置/回溯后丢弃旧任务结果，防止旧状态和已放弃的未来重新进入历史。
- 历史保留时间、记录数量及 64 MiB 压缩有效载荷上限继续生效；临时缓冲另计。退出/关闭时清理后台线程。
- 保留真实速率统计、模拟时钟、3D 倍率、普通存档格式、着色器、回溯绑定和上一版摇杆修复。

## 验证

- 最终 assembleDebug、testDebugUnitTest、lintDebug 构建成功。
- 48 项 JVM 回归测试通过，Lint 0 项错误、18 项警告。
- 5 组原生宿主测试通过：历史队列、真实 zlib 编解码/CRC、后台线程、调度、异步时间线。包含 10,000 次随机历史操作、512 次后台任务循环、工作线程重复启动/停止和分配归零检查。
- 故意阻塞后台压缩，确认模拟线程可继续处理且拒绝第二个在途任务；执行回溯后释放后台任务，验证旧未来不会重新插入历史。验证压缩失败恢复和任务未完成时退出清理。
- APK 签名校验通过，与此前测试版证书一致；5 个原生库的 ZIP/ELF 均满足 16 KiB 对齐检查；192 个 shader 资源与源码及上一版一致。
- 源码包 736 个文件逐个比较一致，不含构建缓存、SDK 和本机 local.properties，包含源码说明及宿主测试工具。

原生宿主测试使用生产队列、调度、后台线程及压缩代码和真实 Windows x64 zlib；机器状态内容、时钟及 Windows pthread 接口为测试适配，不能替代实际 NDS 游戏状态恢复或 Android 耗时测量。

**没有 RP Nova 真机测量，不能承诺固定 100% 或量化改善幅度。** 状态复制和后台 CPU/内存带宽仍有开销。建议保持《心金》同一地点和设置，回溯开/关各运行一段时间，分别比较 1 倍与 2 倍；再检查回溯、读档、重置和退出。
