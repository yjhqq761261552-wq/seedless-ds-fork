# SeedlessDS 1.0.8 优化与验证

基于自制 1.0.7-vulkan，保留此前官方 1.0.1 合并、RP Nova 左摇杆修复及回溯功能。版本码 118，包名 com.seedlessds.app.debug，与之前版本同证书，可直接覆盖安装；已安装到 Nova。参考 WatermelonDS 0.8.0.rc3 的应用层实现与设计，提交 `9bd6a0db59f944cda961e1df7f6e692eb6d4e65b`。

## 已修复的问题

- F1–F3：存档检查短写、压缩/分配、flush/close、线程启动和改名结果；请求先取得单次执行资格，再写临时文件。只有提交成功才替换旧档。文件路径使用原子 rename；SAF 使用可恢复的旧档改名、提交、回滚协议，权限/提供者异常返回失败，不能证明任意 SAF 提供者具备断电原子性。
- F2：UI、快捷键及调试入口等待真实完成结果；存档菜单异步加载。主存档与 RetroAchievements 附加档通过 SHA-256 关联，读到不匹配的附加档时重置成就进度。旧 `.dss` 可读；没有关联标记的旧 `.ra` 会被忽略并重置，避免套入错误进度。
- F4：截图/缩略图按每屏实际尺度、位深和模式抽样，修正固定 2 倍步长，覆盖 1–8 倍；同时复制同一已完成页的两屏。
- F5：两次帧采样之间的短按保留一次按下边沿；触控 MOVE 仍取最新位置。暂停、取消、读档及断连清除旧输入；设备和触屏来源分别管理，防止其他设备或副屏取消当前操作。
- F6：OpenSL 队列计数使用原子读改写，缓冲复用归属由回调控制，移除破坏归属的临时静音入队。
- F7：存档菜单批量读取元数据，后台解码缩略图和删除，显示真实成功/失败，触摸选择同步手柄游标；快捷存档菜单与热键统一到同一槽位；修复覆盖/读档确认设置未生效，菜单和快捷键都遵循设置，取消不写盘。
- F8：RetroAchievements 按模拟帧完成事件同步评估，核心内存处于帧边界；回调、网络响应和状态读写串行保护。启动读档也等待实际结果后再应用对应附加档。本轮没有登录账户触发真实成就，验证范围是协议和逐帧钩子。

## 性能优化与设置

- 音频：新增 **音频 → 低延迟音频输出**，默认开启；重新打开游戏生效。API 26+ 动态加载 AAudio，旧系统或打开失败/断连时回退 OpenSL。输出采用设备采样率、无锁单生产者/单消费者 PCM 环形缓冲及线性重采样；先预填充再启动，处理暂停、静音、音量与重复恢复。欠载时有界扩大缓冲。Nova 实际 48kHz，常见 API 缓冲 1536 帧（32ms）；这不是整体声音延迟，也不能直接与旧队列容量计算值相减宣称收益。
- Vulkan：以新帧条件变量和 GPU fence 等待代替固定 2ms 轮询；双显示复用两槽不可变 CPU 帧，副屏落后取较新帧，不积压；仅上传当前可见屏幕。驱动格式/呈现模式失败时尝试下一组合并缓存失败组合，维持每显示器最多一个 GPU 提交在执行。
- 滤镜：Vulkan 新支持内置 **FXAA**，保留 None / Linear；修正原 GLSL FXAA 错用 alpha 当中心亮度的问题。Vulkan 为单次 FXAA，GL 原路径还含 Quilez 放大插值，二者并非逐像素相同。FXAA HQ、SMAA、自定义/修改过的同名滤镜继续兼容回退 OpenGL。
- 回溯：保留后台压缩、原始缓冲复用和有界历史，新增 **采样间隔 1–3 秒**，默认 1 秒，支持全局与每游戏设置。间隔越长，录制成本越低，倒退粒度越粗；修改间隔会重建历史。
- 统计：新增输入采样、帧间隔、回溯抓取、画面复制 P95/P99，以及音频欠载/XRun、Vulkan CPU 提交与帧年龄日志。帧年龄截至 CPU 提交/呈现交接，不能代表物理面板发光时间；HUD 与模拟帧统计也不是完整 GPU/光学帧时间。

Android 13 / QCS8550 / Adreno 740，单物理显示窗口 1280×960。使用设备已有《起源心金4.0正式版》，读取同一即时存档，静止场景运行；每项约 24 秒，均开启回溯录制、采样间隔 1 秒。表中 HUD 排除刚启动的 0% 过渡值，每项仅约 2 个有效 HUD 样本，P95/P99 来自原生更密集统计，不能据此证明所有场景无卡顿。

AAudio 启动阶段记录的少量缺数据回调与系统 XRun 分开统计；原始数值保留在验证 JSON。没有对所有音频路线进行声学测量，也没有基于无按键静止场景估算实际操作延迟。

性能矩阵使用相同原生代码的前一个 APK；最终构建只追加了存档确认界面修复，并再次在 Nova 验证菜单及快捷键的确认/取消。原生库内容一致。

已验证新建、覆盖和读取 UI 存档位 3，日志均为 completed=1，缩略图正确，读档恢复游戏；连续 5 次菜单暂停/恢复及 ADB 回溯键组合操作。不同倍率、FXAA/None、OpenGL、关闭低延迟音频的兼容路径均启动运行，未见进程崩溃。

模拟副屏的 800×600 / 640×480 两种尺寸、移除重接及主副 Vulkan 线程已运行检查；详见 JSON。它验证的是系统虚拟显示路径，真实双物理屏、不同刷新率、HDMI/USB-C 和物理副屏触控尚未覆盖。

测试后恢复本轮原有设置、按键映射和系统模拟副屏配置；原有 8 个存档文件 SHA-256 对照一致。测试新建的槽位 3、9 文件均已清理。根据用户指示，后续测试没有继续制作备份。

## 自动验证与复现

- Android assembleDebug、79 项 JVM 测试通过；Lint 0 错误 / 24 警告。保留既有警告，未宣称零警告。
- 生产存档代码 21 个写入故障分支，提供者事务/回滚 JVM 测试、完成/取消协议、短按/触控/并发输入、PCM 多采样率/回绕/溢出/清空、直方图和 120 次模拟帧回调均通过。
- 9 组画面/WSI 主机检查通过，含 1–8 倍两屏模式及位深组合、RGB565 全值域、并发快照；5 组原生回溯检查通过，10,000 次环形缓冲操作、512 次线程复用，无遗留分配。
- Nova 独立原生进程检查生产 AAudio 适配器的预填充、音量/重采样、静音与暂停、断连/打开失败回退；使用测试驱动，不是声学测试。另检查真实共享帧池的 1000 次并发发布、8 个等待者的唤醒/取消/超时。
- 两个 Vulkan 1.0 着色器与随源 SPIR-V 一致；110 个 GLSL 配置、147 个阶段配对编译链接通过。APK 资源与源码逐字节对照；v1/v2 签名与 5 个 ARM64 原生库的 ELF LOAD / APK 偏移 16KiB 对齐通过，无 libaaudio.so / libvulkan.so 硬加载依赖。

构建使用 JDK17、SDK35、Build Tools34.0.0、NDK25.2.9519653、CMake3.22.1。设置 local.properties 的 sdk.dir 后运行：

```text
gradlew.bat --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
python tools/run_safety_host_tests.py --ndk <NDK>
python tools/run_vulkan_host_tests.py --ndk <NDK>
python tools/run_rewind_host_tests.py --ndk <NDK>
python tools/run_android_adapter_tests.py --ndk <NDK> --adb <adb> --serial <设备序列号>
python tools/compile_vulkan_shaders.py --glslang <glslang> --check
```

源码内包含固定版本的原生依赖源压缩包和复现脚本；初次 Android 构建仍需 Gradle/Android 依赖。Windows 原生主机测试需要 NDK 和 Git for Windows 的 zlib1.dll。源码包不含 ROM、用户存档、账户资料或构建缓存。
