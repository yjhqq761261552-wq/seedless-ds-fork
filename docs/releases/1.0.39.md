# 原声加速修复与 RP Duo 滤镜

加速时使用 SoundTouch 保留音高，音乐和音效节奏随游戏加快。修复此前加速连续爆音，以及 1.0.38 加速声音尖锐的问题。RP Duo 用户已确认 1.0.39“音色自然了，效果合适”。

包含按上下屏实际画面尺寸适配的 Vulkan 柔和颗粒、柔和颗粒＋和 Nova 磷光点滤镜，以及低延迟音频的暂停恢复和异常回退修复。

## 下载选择

| 文件后缀 | 用途 | Android 包名 |
|---|---|---|
| `replacement.apk` | 原包名替换版 | `com.seedlessds.app` |
| `coexist.apk` | 与官方版共存，可更新本分支旧共存版 | `com.seedlessds.app.debug` |
| `src.zip` | 两版对应源码，包含 SoundTouch 及构建配置 | — |
| `SHA256.txt` | 安装包和源码校验值 | — |

**替换版与官方版签名不同。首次换用替换版，请先导出游戏存档和配置，再卸载官方版并安装。** 直接覆盖官方版会因签名不匹配而失败。替换版后续可使用本分支同签名安装包更新。

两种包名的数据各自独立，需要分别授权游戏目录并导入存档。两个 APK 均为 ARM64，最低 Android 5.0，版本为 `1.0.39-natural-audio`，版本号为 `149`。

## 验证

- 替换版与共存版各 115 项应用测试通过，34 项 AAudio 回归、9 项 OpenSL 队列回归通过。
- RP Duo 运行生产变速代码，检查 0.5–64 倍的音高、时长、分块一致性、切速与缓存清理。
- 两种安装包构建与包名、签名检查通过，替换版通过独立 Lint 检查。
- 共存版完成 RP Duo 用户听测确认。替换版尚未在掌机安装听测，所有游戏和长时间高倍率运行尚未逐项覆盖。
