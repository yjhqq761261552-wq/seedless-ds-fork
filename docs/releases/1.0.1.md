# SeedlessDS 双屏修复版

版本：1.0.1-dualscreen（versionCode 111）  
包名：com.seedlessds.app.debug；架构：arm64-v8a；最低 Android API：21。

## 安装

APK 使用与原 pip-size-debug APK 相同的 Debug 签名，可覆盖升级同包名测试版，无需卸载。签名证书 SHA-256：

`99e2395bd7c458a577e6bc4f4c7237a7474cb20a178fad07313c2778a7943165`

这是 Debug 测试包。升级保留已有设置；如果此前关闭了“保持比例”，请在双屏预设中开启它，以保持 NDS 的 4:3 画面。

## 主要修复

- 隔离主副屏的回退着色器，检查链接、纹理上限和 FBO 完整性，修复 SMAA/4XBR 的 GLES 2.0 源码兼容问题。
- 修正交换上下屏后的副屏触摸；移出画面、隐藏画面和销毁 Surface 时释放触摸。
- 重做双屏尺寸计算；不同 DPI 下整数缩放优先，物理同尺寸允许近似；小窗口缩小适配，避免裁切。
- 修复游戏内副屏设置切换、显示失败回退、退出线程清理，以及拔掉副屏后仍延迟主屏的问题。
- 改用原生 EGL KHR fence，并为不支持 fence 的驱动保留完成等待回退；副屏换帧不再持有纹理读取占用或 Surface 元数据锁。
- 几何调整不重复编译同一 shader，升级应用时可更新内置 shader，同时保留用户改过的文件。
- 补齐 Lint 发现的 Android 5.x 屏幕尺寸读取、列表方法和通知权限兼容处理。

## 验证结果

- 最终 `assembleDebug`、`testDebugUnitTest`、`lintDebug` 构建成功。
- 11 项 JVM 回归测试通过；其中参数化循环覆盖 50 组双屏尺寸/整数缩放组合。
- 110 个着色器配方、147 组顶点/片元程序：GLSL ES 1.00 静态编译与链接全部通过。
- APK 的 192 个 shader 资源与交付源码完全一致。
- Android Lint：0 项错误，29 项警告。剩余警告包括旧的 API 弃用、控件可访问性和编辑覆盖层分配等；没有通过整体关闭检查掩盖错误。公开 Activity 的按键回调因 AndroidX 父类转发注解产生 RestrictedApi 提示，仅在两个回调方法上做了说明性抑制。
- APK 签名校验通过，与原测试包证书相同；ZIP 页面与原生 ELF LOAD 段均核对为 16 KiB 对齐。

未进行 Android 安装运行、游戏实测或双屏真机测试，因此不能承诺所有 Adreno/Mali 驱动或厂商副屏触摸路由均正常。折叠屏铰链识别未新增，副屏仍需支持 Android Presentation。

建议先验证：上下屏互换后的副屏点击、两屏四角触摸、保持比例/同尺寸/整数缩放组合、SMAA 与 LCD 滤镜、进出游戏、息屏和热插拔。
