# SeedlessDS 1.0.9 渲染器设置与验证

基于自制 1.0.8-optimized，版本名 1.0.9-renderer、版本码 119；包名、签名不变，可覆盖升级，已安装到 Nova。

## 使用与行为

在 **设置 → 屏幕 → 渲染器** 选择 **OpenGL / Vulkan**。该选项位于“图像滤镜”之前，默认 OpenGL；旧版没有渲染器字段的配置，即使曾开启 Vulkan 低延迟，也默认 OpenGL。全局与每游戏配置分别保存、继承和清除覆盖。

| 渲染器 | 可选图像滤镜 | Vulkan 低延迟开关 |
|---|---|---|
| OpenGL | 设备上已安装的完整 GLSL 滤镜列表，含自定义效果 | 隐藏，旧开关值不会启用 Vulkan |
| Vulkan | 内置无滤镜、线性、FXAA | 在图像滤镜下面显示 |

从不兼容的 OpenGL 滤镜切到 Vulkan 时自动选择“无滤镜”。旧配置若包含 Vulkan + SMAA/自定义滤镜等组合，读取时也规范为 Vulkan + 无滤镜。Vulkan 效果直接使用内置着色器，不再依赖或校验同名 GLSL 文件，**不再因为滤镜而回退 OpenGL**。OpenGL 着色器资源与 1.0.8 完全一致。

Vulkan 低延迟从“视频”页迁入“屏幕”页：**关闭仍是 Vulkan，使用同步 FIFO 呈现；开启仍是 Vulkan，按驱动能力优先 Mailbox / Immediate，之后尝试其他可用模式。** 主屏和副屏使用同一设置，切换时重建各自交换链。

更换渲染器须先关闭游戏，运行中的选择行会禁用并说明原因，避免同一窗口的 EGL/Vulkan 连接互相争用。滤镜和 Vulkan 低延迟可以在游戏中修改；屏幕页显示当前实际后端。

外屏延迟校准仅在 OpenGL 下可编辑。Vulkan 使用最新共享帧，保留的旧延迟值不会使后端切回 OpenGL；重新选择 OpenGL 后原校准值仍保留。Android 不支持、驱动初始化失败或诊断捕获会话仍有明确提示的兼容路径，并显示实际后端；本版没有承诺所有驱动都能成功使用 Vulkan。

## 验证

- Android 构建成功，**86 项 JVM 测试全部通过**；Lint **0 错误 / 27 警告**，其中新增 3 项为已不再引用的旧 Vulkan 提示资源。
- 全局/每游戏读写、继承和清除覆盖、默认 OpenGL、旧低延迟标记、切换时滤镜规范化、保留自定义 OpenGL 列表、低延迟与渲染器独立等回归通过。
- 10 组生产像素/快照/WSI 策略主机检查通过；新增关闭低延迟时只选 FIFO 的检查。核心源码和 GL 着色器未改动，因此没有将 1.0.8 的音频、回溯实测重复标为本轮测试。
- Nova 菜单实际操作确认默认 OpenGL、渲染器顺序、完整 GL 列表、Vulkan 三项列表和条件开关；从 HQ2X 切 Vulkan 自动选无滤镜，通过菜单保存 Vulkan + FXAA + 低延迟关闭并打开游戏，实际日志为 **Vulkan / FIFO / lowLatency=0**。
- 游戏中开启低延迟后，日志转为 **Vulkan / Mailbox / lowLatency=1**，没有 OpenGL 回退。
- 9 项约 8 秒的兼容运行：旧版默认配置、Vulkan 三滤镜 × 低延迟开/关、Vulkan 不兼容持久化滤镜规范化、OpenGL + SMAA + 旧低延迟开启。全部后端符合预期，未见进程崩溃。这些短测不能代表长期性能或所有游戏。
- 临时 800×600 模拟副屏，FXAA 下分别验证低延迟开/关；主副屏均使用对应 Mailbox/FIFO。故意保留 2 帧旧校准值，没有因此回退 GL。它不代替真实双物理屏测试。
- APK 签名、安装后 SHA-256、5 个 ARM64 库的 ELF LOAD / APK 偏移 16KiB 对齐通过；没有 libvulkan.so / libaaudio.so 硬加载依赖。
- 原有 8 个存档 SHA-256 未变；测试后恢复原设置、按键映射和系统模拟副屏设置，未额外制作备份。

Vulkan 仍呈现软件核心完成的 DS 图像；没有加入 Vulkan 硬件 3D。本轮没有光学或声学端到端延迟测量。

## 构建

JDK17、SDK35、Build Tools34.0.0、NDK25.2.9519653、CMake3.22.1；配置 local.properties 的 sdk.dir 后：

```text
gradlew.bat --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
python tools/run_vulkan_host_tests.py --ndk <NDK目录>
```

源码携带固定原生依赖源压缩包和回归脚本，不含用户 ROM、存档、账号、local.properties 或构建缓存。首次 Android 构建仍需获取 Gradle/Android 依赖。
