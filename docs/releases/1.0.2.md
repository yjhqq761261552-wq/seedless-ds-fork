# SeedlessDS 1.0.2-lowlatency

已基于 Grok 低延迟源码完成修复和进一步优化，并打包 Debug APK。版本号 112，包名 com.seedlessds.app.debug，arm64-v8a，最低 Android API 21。与之前交付 APK 的签名相同，可覆盖安装同包名、同签名测试版并保留数据。

## 主要变化

- 修复 API 26–29 上错误调用无缓冲触摸 API 的兼容问题，改用 API 21 起支持的 MotionEvent 重载。
- 增加“低延迟触摸”开关，默认开启，可全局或单游戏保存，便于真机对比。
- 移除无效的历史触摸点重放；方向、扳机批量提交，重复状态不再反复调用 JNI。
- 原生线程一次读取完整输入快照，避免按键、触笔状态和坐标混合；短锁内只复制输入。
- 分离虚拟按键、实体按键、摇杆状态后合并，修复互相释放和手柄死区设置失效。
- 修复多指触笔、两屏触摸释放冲突、最右列/最下行点击映射，以及暂停/菜单/重置/读档/隐藏虚拟控件后的输入释放。
- 常规帧在新画面可用后、覆写共享纹理之前等待副屏读取，减少过早撤销副屏待显示帧。保留 EGL fence 同步和驱动回退路径。
- 保留此前的双屏比例、交换屏幕映射和着色器修复；主屏延迟默认 0。

## 安装后的设置

升级保留已有设置。如果已有安装的“主屏延迟”仍是 1 帧，请手动改为 0；不自动覆盖此前针对电视设置的同步校准值。“低延迟触摸”仅影响 DS 触屏事件分发，若轨迹抖动可关闭对比。高分辨率和多阶段滤镜仍会增加渲染耗时，建议以 1× 分辨率、无滤镜作响应对比基线。

## 实际验证

- 最终 assembleDebug、testDebugUnitTest、lintDebug 成功。
- 29 项 JVM 测试全部通过：11 项双屏几何、12 项输入聚合/并发/死区、6 项触笔/坐标测试。像素映射覆盖全部 49,152 个 DS 像素中心。
- Lint 0 项错误、18 项警告，仍有原有 API 弃用、可访问性等提示；没有整体关闭检查来隐藏错误。
- 生产原生输入快照代码的宿主并发测试：3 写线程、3 读线程，90,000 次写入和 90,000 次读取，无不完整快照。宿主使用 Windows SRW 锁适配，Android 构建使用 pthread。
- APK 的 192 个 shader 资源与本次源码、此前已验证的双屏修复版完全相同；本次未重新宣称完成 shader 真机验证。
- APK v1/v2 签名验证成功；ZIP 对齐检查通过，5 个原生库的 ZIP 偏移和 ELF LOAD 段均满足 16 KiB 对齐检查。
- 源码包逐文件校验通过，共 708 个文件；不含构建目录、SDK、Gradle 缓存及本机 local.properties，保留测试和 Debug 签名文件。

本次没有 Android 设备或双屏真机测试，未测量输入到显示的毫秒数。测试证明编译、静态兼容与相关逻辑通过，不能替代实际游戏、驱动和厂商副屏触摸路由验证。没有改变模拟时钟、音频节奏或帧边界采样。

建议重点实测：两屏四角和手写轨迹，多指按键+触笔同时使用，实体键与虚拟键同时按住后分别松开，暂停恢复，读档/重置，交换上下屏，切换布局和副屏热插拔。双屏还需确认 4:3 比例及所选滤镜实际显示正常。
