# SeedlessDS 1.0.3-rewind

已在 1.0.2-lowlatency 基础上新增回溯，保留此前双屏、着色器和输入延迟修复。versionCode 113；包名 com.seedlessds.app.debug；arm64-v8a；最低 Android API 21。Debug 签名与此前交付版本相同，可覆盖安装同包名、同签名测试版。

## 使用方法

1. 进入“设置 → 按键 → 回溯”，开启回溯。默认关闭，默认历史为 30 秒，可选 10/30/60 秒。
2. 点击“绑定回溯按键”，在“模拟器功能 → 回溯（按住）”绑定手柄或键盘按键，三个映射配置分别保存。
3. 正常游玩后，短按回退一个记录点，按住连续回退，松开继续；达到最早记录时等待松开。
4. 如需触屏按钮，在“触摸设置 → 特殊按钮”里把任一特殊按钮分配为“回溯（按住）”。

没有占用快速存档槽，没有生成回溯存档文件。约每 60 个模拟帧记录一次，按记录点回退，不是逐帧倒放。压缩历史有效载荷上限为 64 MiB，临时缓冲和模拟器自身内存另计，因此实际保留时长可能小于所选值。关闭功能、重置、读档、切换游戏和退出会失效历史；暂停/菜单、窗口失焦及手柄断开会取消按住状态。

回溯期间静音。成就系统在回溯前等待正在进行的帧评估结束，回溯期间不评估，在新时间线上重置运行时进度后继续。修复了默认 DS 按键改绑特殊功能后仍触发原动作的冲突问题。
